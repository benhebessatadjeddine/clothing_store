# Lumina Milano — Italian Luxury E-Commerce Platform

A modern, responsive luxury fashion platform built with **React**, **Redux Toolkit**, and **Tailwind CSS**. Inspired by Italian haute couture and curated in Milan, offering refined clothing and footwear collections with seamless browsing, filtering, wishlist, and shopping cart management.

---

## ✨ Features

- **Modern UI & Animations:** Fluid animations powered by Framer Motion with custom dark theme aesthetics.
- **Product Filtering & Search:** Real-time filtering by category, brand, price, gender, and stock availability.
- **Cart & Wishlist Management:** Interactive shopping cart with order summary and persistent wishlist tracking.
- **User Authentication:** Sign up, sign in, and profile management.
- **Order History:** Complete order placement and review flow.
- **Responsive Design:** Optimized for mobile, tablet, and desktop viewports.

---

## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/benhebessatadjeddine/clothing_store.git
   cd clothing_store
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

## 🛠 Tech Stack

- **Frontend:** React 18, Vite, React Router v6
- **State Management:** Redux Toolkit
- **Styling:** Tailwind CSS, DaisyUI
- **Animations:** Framer Motion
- **Icons:** React Icons
